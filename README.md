# LEVELUP — сайт автосервиса

Это стартовый проект адаптивного сайта на HTML, CSS и JavaScript. Он не требует платного конструктора.

## Что уже есть
- Адаптивная главная страница для телефона и компьютера.
- Разделы услуг, работ, цен, отзывов, записи и контактов.
- Форма записи, которая подготавливает сообщение и открывает Telegram `@ali_zod_aliev`.
- SEO-заголовок, описание, canonical, Open Graph, Schema.org AutoRepair, `robots.txt` и `sitemap.xml`.
- Начальная конфигурация Decap CMS для будущего управления контентом.

## Важно перед публикацией
1. Проверьте цены, адрес, телефон и ссылки.
2. Замените демонстрационные блоки портфолио реальными фотографиями LEVELUP.
3. Подтвердите домен `levelup.uz` и настройте DNS. Canonical и sitemap сейчас используют этот домен как пример.
4. Проверьте, что ссылка Telegram с предзаполненным текстом открывается на вашем iPhone и Android.
5. Не добавляйте отзывы, рейтинги или фотографии, которые не принадлежат реальным клиентским работам.

## Как открыть сайт на компьютере
Самый простой вариант — открыть `index.html` двойным нажатием. Для локального сервера в папке проекта выполните:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Как опубликовать бесплатно на Cloudflare Pages
1. Создайте аккаунт GitHub и новый репозиторий `levelup-site`.
2. Загрузите туда все файлы проекта.
3. В Cloudflare откройте Workers & Pages → Create → Pages → Connect to Git.
4. Подключите репозиторий. Для обычного статического сайта укажите build command пустым, output directory `/` (если интерфейс не принимает `/`, используйте корень проекта).
5. После публикации подключите свой домен в настройках Pages.

## Управление сайтом через /admin
В папке `admin` лежит стартовая конфигурация Decap CMS. Это не готовая авторизация: чтобы редактор мог безопасно сохранять изменения в GitHub, нужно настроить OAuth/Git Gateway и заменить `YOUR_GITHUB_USERNAME/levelup-site` на настоящий репозиторий. Не публикуйте токены в `config.yml`.

На первом этапе сайт можно публиковать без CMS, а затем настроить панель управления отдельным уроком.

## Что изучать по порядку
1. `index.html` — структура блоков и тексты.
2. `styles.css` — цвета, размеры, адаптивность.
3. `script.js` — меню и отправка заявки в Telegram.
4. SEO-файлы — как поисковики находят сайт.
5. GitHub и Cloudflare Pages — как изменения попадают в интернет.
6. Decap CMS — как редактировать контент через панель.
